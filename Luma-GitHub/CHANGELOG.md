# Changelog

## 1.2.0

The supplied archive identifies itself as version 1.2.0. Its existing Persian notes describe this version as introducing the Luma name and icons while retaining the Persian dark interface, local typography, toggle control, and account-path handling from earlier versions.

Current package includes:

- Luma branding and icons.
- Persian popup with enable/disable control and diagnostic status.
- Flow reload / unsupported-country return action.
- Account-path normalization when matching RPC routes.
- Remote JSON configuration support.

The GitHub preparation adds English and Persian documentation, data-handling notes, an issue template, and a publication checklist. Runtime code, manifest version, and supplied assets are unchanged. No live Flow access test has been performed.
