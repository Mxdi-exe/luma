# Luma v1.2.0

Luma is a Chrome extension designed to help with the “Country unsupported” error on Google Flow.

## Included

- Persian dark popup with an on/off switch and status messages.
- Reload button with handling for the unsupported-country page.
- Matching support for numeric Google account paths.
- Bundled Luma icons and local fonts.

## Manual installation

Extract the extension ZIP, open `chrome://extensions`, enable Developer mode, select Load unpacked, and choose the folder containing `manifest.json`. Open Flow and refresh the page after changing Luma's switch.

Requires Chrome 111 or later and access to the remote configuration service at `flow.cfcnode.com`. This helper does not grant Flow account entitlements or guarantee access. Read README.md and PRIVACY.md before use.

Luma افزونه کروم برای کمک به رفع خطای Country unsupported در Google Flow است. این نسخه شامل رابط فارسی تیره، سوییچ دسترسی، نمایش وضعیت، دکمه بارگذاری مجدد و در نظر گرفتن مسیرهای چندحسابی است.

برای نصب دستی، ZIP را استخراج کنید و پوشه دارای manifest.json را از طریق Load unpacked در chrome://extensions بارگذاری کنید. به کروم ۱۱۱ یا بالاتر و دسترسی به سرور تنظیمات نیاز دارید. پس از تغییر سوییچ، صفحه Flow را تازه‌سازی کنید.
